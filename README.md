# 🚗 Brabush Car Dealership Website

Welcome to the official **Brabush Car Dealership** website — your one-stop destination for exploring, comparing, and purchasing premium cars. This WordPress-based site provides a modern, user-friendly platform for both customers and administrators to manage everything from listings to lead generation.

---

## 🌐 Live Demo

📱 Fully responsive across mobile, tablet, and desktop

---

## 🧰 Built With

* 🧱 **WordPress** – Core CMS platform
* 🎨 **Elementor** / **WPBakery** – For drag-and-drop page building
* 🚗 **Auto Listings** or **Car Dealer Pro** plugin – For car inventory management
* 🔍 **Yoast SEO** – For search engine optimization
* 📩 **Contact Form 7** – For inquiry and lead forms
* 🛠️ **Custom Theme** – Based on dealership branding (Brabush)

---

## 🔑 Features

* 🏷️ Showcase new and used cars with detailed specs
* 📸 Car image galleries with sliders
* 🔍 Advanced search and filter (by brand, price, year, fuel, transmission, etc.)
* 📆 Book a test drive feature
* 📞 WhatsApp & call buttons for instant support
* 📝 Finance inquiry & contact forms
* 📰 Blog/news updates section
* 🧭 Google Maps integration
* ⚙️ Admin dashboard for managing listings and leads

## 🚀 Getting Started

### Installation

1. Clone the repo or upload the theme to `/wp-content/themes/brabush-theme/`
2. Install required plugins:

   * Auto Listings or Car Dealer Pro
   * Contact Form 7
   * Yoast SEO
   * Elementor (optional)
3. Import demo content (if provided)
4. Customize logo, colors, and content via the WordPress Customizer
